## 一、研究问题

我要做的是一套以 Android 手机为核心的环境监测与远程控制系统：设备端负责采集温湿度等环境数据，服务端负责接收和存储，手机 App 负责展示数据和远程控制。App 里同时实现两条取数通道——MQTT 长连接订阅和 HTTP 轮询。

这个方向目前的问题是：MQTT 和 HTTP 到底哪个更适合移动端物联网场景，网上多数文章是定性分析，缺少在同一套系统里做定量对比的数据。所以我打算固定上报频率、payload、网络环境这些变量，把两种机制的端到端延迟、消息到达率、断网恢复情况都测出来，最后给出"什么场景选什么机制"的结论。

## 二、最低完成要求
