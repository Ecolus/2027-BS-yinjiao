## 一、研究问题

本论文面向环境监测场景，设计并实现一套以 Android 移动端为核心的物联网环境监测与远程控制系统。系统由环境数据采集端、服务端与移动端 App 三部分组成，App 同时通过 MQTT 长连接订阅与 HTTP 轮询两条通道获取数据。当前问题在于：移动端在不同上报频率、payload 大小、网络环境下，MQTT 与 HTTP 两种通信机制在端到端延迟、消息到达率、断网恢复能力上的差异缺乏定量比较，移动端选型往往凭经验。本论文拟在固定控制变量的前提下，对两种机制进行定量对比，并给出"何种场景应选哪种通信机制"的结论。

## 二、最低完成要求

- [ ] 错误或异常情况分析：弱网、断网恢复、重连后数据补传等异常工况
