# reading_notes/ 精读阅读卡

老师要求：至少精读 5 篇文献，每篇写一张简短阅读卡，内容包括：研究问题、方法、数据/环境、指标、主要结论、与本课题的关系。

## 使用方式

1. 打开对应文献的 PDF 或数据库页面（链接见各文件）。
2. 快速通读摘要 + 引言 + 实验/结论部分（每篇 30–40 分钟足够）。
3. 在文件末尾"我的阅读笔记"里按模板填写六栏。
4. 每完成一篇，把 `literature_list.md` 第三节的精读计划勾掉一项。
