## 摘要要点（导读）

- 目标：综述 IoT 应用层通信协议（请求-响应类与发布-订阅类），评估它们在雾计算、云计算环境下的适用性。
- 方法：按主要特征对比各协议，并从延迟、能耗、网络吞吐三个性能维度分析；最后把各协议放到 IoT→雾→云各层段讨论选型。
- 与你的课题的关系：这篇综述给了"通信协议选型"的系统框架，你的论文"相关技术/相关工作"章节可以直接借它的分类与性能维度（延迟、能耗、吞吐），并为你的 MQTT vs HTTP 对比提供学术定位。
